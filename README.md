# Amir Mobasheraghdam — ESP32-C3 Idea Beacon

An interactive ESP32-C3 project developed by **Amir Mobasheraghdam**.

The project uses a **Seeed Studio XIAO ESP32-C3** with a **1.3-inch OLED display**, Wi-Fi captive portal, BLE and a local web interface.

Visitors can connect to the device using Wi-Fi, submit their name and idea, and the new idea is immediately displayed on the OLED.

## Features

- XIAO ESP32-C3
- 1.3" SH1106 OLED
- German scrolling quotes
- Wi-Fi Captive Portal
- BLE device name: Amir
- Guest idea submission
- Instant OLED notification
- Private Admin Dashboard
- Stored messages
- Random famous quotes
- UTF-8 German characters
- Arduino IDE compatible
